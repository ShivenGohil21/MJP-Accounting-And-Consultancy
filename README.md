# MJP Society Accounts & Consultancy

Official website portal for **MJP Society Accounts & Consultancy**, specializing in Housing Society Computer Accounting, Statutory Register Audits ('I' & 'J'), Model Bye-laws 2014 Adoption, Legal Documentation, Dues Recovery, Conveyance / Deemed Conveyance, and Redevelopment Services across Mumbai.

## 🚀 Features

- **Modern Responsive Design**: Built with React, Vite, Framer Motion, and Tailwind CSS aesthetic design system.
- **Service Offerings**: Complete overview of 10+ core society consultancy & accounting services.
- **Direct Proposal Request System**: Interactive proposal request form with instant inquiry delivery.
- **Client Societies Portfolio**: Interactive showcase of active societies managed by MJP.
- **Interactive Governance FAQs**: Detailed guidance on Cooperative Society Bye-laws, Audits, and Statutory Compliance.

## 🛠 Tech Stack

- **Framework**: React.js, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
